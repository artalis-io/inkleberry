# Historical evidence

This directory retains historical designs, qualification reports and recorded
benchmark receipts. They describe their recorded revisions, not current test
commands or supported APIs. It is excluded from production packages.

The retired Zig implementation, comparison harnesses, experimental utilities
and legacy service example have been removed. Current validation uses the C
regression suites, fixed golden tokens, native recovery tests and performance
gates documented in `../docs/releases.md`. Attribution remains in LICENSE,
NOTICE, THIRD_PARTY.md and the retained CUDA pins in UPSTREAM.json.
